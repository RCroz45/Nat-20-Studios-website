Jake Ridley

Lead Project Manager / Lead Programmer

Leads the development team and oversees the overall direction of the project. Reviews progress regularly to ensure tasks are completed on schedule and assigns responsibilities to team members based on the needs of the project.

Coordinates communication within the group so development remains organised and efficient. Defines both the functional requirements, which describe what the system must do, and the non functional requirements, which outline performance, reliability, and usability expectations for the final product.

Rhys Crozier

Deputy Project Manager / Documentation / Web Design

Supports the lead project manager in organising and coordinating project tasks. Tracks development progress and records important updates so the team maintains clear documentation throughout the project lifecycle.

Responsible for producing written reports and structured documentation that explain the system and its development. Designs and maintains the company website, ensuring it presents project information clearly and professionally.

Liam Groves

Documentation / Web Design

Maintains organised documentation that records the progress, design decisions, and technical details of the project.

Ensures written records remain clear, structured, and accessible to the rest of the team. Assists with the design and layout of the company website, helping structure pages and content so information remains easy to navigate and visually clear for users.

Leo Scripps

Tester

Tests development builds to ensure the software performs as expected. Runs practical tests to identify bugs, errors, or unexpected behaviour within the system.

Carefully documents any issues discovered during testing and reports them to the programming team so they can be corrected. Helps maintain the overall quality and reliability of the software before it reaches users.

Lee Dixon

Programmer

Develops core system functionality and contributes to building the technical features required for the project. Writes and improves code to implement both functional and non functional system requirements.

Works closely with other developers to ensure different parts of the system integrate correctly and operate reliably.

Daniel Matthews

Tester / Presentation Designer

Tests development builds to confirm that implemented features function correctly and meet the required standards. Identifies issues during testing and reports them clearly to the development team.

Designs presentation materials used to explain the project to clients or evaluators, ensuring the system and its purpose are communicated clearly through organised visual slides and supporting information.

Matthew Gooch

Programmer
